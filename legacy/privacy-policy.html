Privacy Policy

Study Library Manager Application

Effective Date: January 1, 2026

DA Software Systems built the Study Library Manager application as a commercial service. This service is intended for use by library administrators and staff to manage students, seat allocations, and payments within a study library environment.

This page explains how we collect, use, and protect information when the application is used.

Information We Collect

The application may collect the following information:

  • Student names
  • Phone numbers
  • Seat allocation information
  • Payment records
  • Library membership details

This information is entered by the library administrator for managing library operations.

Device Information

We may collect limited device information such as:

  • Device model
  • Operating system version
  • Application version

This helps us improve application reliability and performance.

How We Use Information

  • Manage student records
  • Track seat allocation
  • Record payments
  • Provide library management features
  • Improve application performance

Data Storage

Application data may be stored securely using cloud infrastructure. The application may use backend services such as Google Firebase for data storage and synchronization.

Library administrators are responsible for the data they manage in the application.

Data Security

We take reasonable measures to protect stored information. However, no method of transmission over the Internet or electronic storage is completely secure.

Third-Party Services

The application may use third-party services to support its functionality.

  • Google Firebase – cloud database and backend infrastructure

These services operate under their own privacy policies.

Application Permissions

The application may request certain permissions including:

  • Internet access – required for data synchronization
  • Notifications – used to provide updates or reminders

User Control

Library administrators have full control over the information stored within the application and can update or delete records at any time.

Children's Privacy

This application is not intended for children under the age of 13. We do not knowingly collect personal information from children.

Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page.
